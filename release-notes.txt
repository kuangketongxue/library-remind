## v5.7.0 — Visual Polish, Screenshot-Ready

Your break reminder just got a visual upgrade. The floating ball, sidebar logo, and empty states are now crisp vector graphics — they'll look identical on every Windows machine, with zero emoji font dependency.

### What's new

- **Redesigned floating ball**: vector lightning icon (study mode) / pause icon (rest mode) with a radial-gradient "energy orb" background and a gradient progress ring. No more emoji rendering inconsistencies across machines.
- **Light theme actually works**: the light theme was silently broken — a hardcoded dark base layer was blocking it. Now it truly switches: the main window and the floating-ball popup both adapt to your theme.
- **Empty states that guide**: new users see a faded lightning icon and "start your first session" prompts instead of a bare "no data". The AI report tab no longer calls the AI when there's nothing to analyze — it shows a friendly guide instead.
- **Vector sidebar logo**: matches the floating ball icon. The entire product now has zero emoji UI dependency, so screenshots look the same everywhere.
- **Popup theme-aware**: the floating-ball info popup follows your theme (light/dark), including the action button color.

### Download

Grab `RestReminder.exe` below, double-click to run. Requires Windows 10/11, no installation needed.

## v5.7.0 — 视觉升级，截图就绪

休息提醒视觉焕新。浮球、侧边栏 logo、空状态全部改为矢量图形——在任何 Windows 机器上渲染一致，不再依赖 emoji 字体。

### 更新内容

- **浮球重绘**：矢量闪电图标（学习态）/ 暂停符号（休息态）+ 径向渐变"能量球"底 + 渐变进度环，告别 emoji 跨机器渲染不一致
- **浅色主题真正生效**：此前浅色主题被硬编码深色底层挡住无法生效，现已修复——主界面和浮球弹窗都会跟随主题切换
- **空状态引导**：新用户看到淡化闪电图标 + "开始第一次学习，趋势图会在这里生长"引导，而非干瘪的"暂无数据"。AI 报告无数据时不再调用 AI，直接显示友好引导
- **侧边栏 logo 矢量化**：与浮球图标完全一致，产品内零 emoji UI 依赖，截图跨机器统一
- **浮球弹窗主题感知**：点击浮球弹出的信息卡片跟随主题变色，浅色主题下不再显示深色

### 下载

下方下载 `RestReminder.exe`，双击运行。需 Windows 10/11，免安装。
