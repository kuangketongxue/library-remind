## 渐变

```css
/* 金色渐变文字 */
background: linear-gradient(135deg, #d4af37, #f0d060);

/* 金色按钮 */
background: linear-gradient(135deg, #d4af37, #f0d060);

/* 进度条 */
background: linear-gradient(90deg, #8b6914, #d4af37, #f0d060);

/* 呼吸灯背景 */
background: radial-gradient(circle, rgba(212,175,55,0.04), #0a0a0c);
```

---

## 设计语言

- **圆角**：12px~20px
- **间距**：8px 倍数
- **字体**：衬线（Georgia）+ 等宽（Consolas）
- **动效**：呼吸灯、渐变进度条、悬浮上移
- **光影**：`box-shadow: 0 8px 32px rgba(212,175,55,0.08)`
