## 🚀 快速开始

### 方法一：一键安装（强烈推荐）⭐

**只需一步，永久生效：**

1. 双击运行 `一键安装.bat`
2. 等待安装完成
3. 完成！程序已在后台运行

**以后每次开机都会自动启动，完全不需要你做任何操作！**

### 方法二：手动安装

#### 1. 安装依赖

```bash
pip install -r requirements.txt
```

#### 2. 运行程序

```bash
# 正常启动（显示窗口）
python rest_reminder.py

# 后台运行（无控制台窗口）
pythonw rest_reminder.py

# 静默启动（开机自启动模式）
pythonw rest_reminder.py --startup
```

#### 3. 设置开机自启动

```bash
# Windows用户（推荐）
双击运行 create_startup.bat

# 或使用Python脚本
pip install pywin32 winshell
python setup_autostart.py
```

## 📖 使用说明

### 主界面操作

- **默认位置**：程序启动后自动显示在屏幕右侧中间位置
- **拖动窗口**：鼠标左键按住窗口任意位置可拖动
- **最小化**：点击右上角"-"按钮最小化到任务栏
- **显示/隐藏**：
  - 双击系统托盘图标快速显示/隐藏窗口
  - 右键托盘图标选择"显示/隐藏"
- **重置位置**：右键托盘图标选择"重置位置到右侧"
- **完全退出**：右键托盘图标选择"退出"

### 工作流程

**休息提醒：**
1. 程序启动后开始60分钟倒计时
2. 每秒更新倒计时和进度条
3. 60分钟后：
   - 弹出系统通知
   - 自动获取B站收藏夹视频列表
   - 随机选择一个视频
   - 用默认浏览器打开（只打开一个）
   - 重新开始计时

**电池监控：**
1. 实时监控电池状态（每秒更新）
2. 显示电池图标：
   - ⚡ 充电中
   - 🔌 已充满
   - 🔋 使用电池
   - 🪫 电量低（<20%）
   - 🖥️ 台式机（无电池）
3. 电量进度条：
   - 绿色：电量正常（>20%）
   - 红色：电量低（≤20%）
4. **断开充电提醒**：
   - 检测到从充电状态变为未充电
   - 自动弹出系统通知（只提醒一次）
   - 重新充电后自动关闭弹窗

## 🔧 自定义设置

### 修改提醒间隔

编辑 `rest_reminder.py` 文件第24行：

```python
self.interval_minutes = 60  # 每60分钟提醒一次
```

修改数字即可，例如改为30分钟：

```python
self.interval_minutes = 30  # 每30分钟提醒一次
```

### 修改收藏夹

编辑 `rest_reminder.py` 文件，找到：

```python
fid = '3648313921'  # 收藏夹ID
mid = '529362421'   # 用户ID
```

替换为你自己的收藏夹ID和用户ID。

**获取方法：**
1. 打开你的B站收藏夹页面
2. URL格式：`https://space.bilibili.com/{用户ID}/favlist?fid={收藏夹ID}&ftype=create`
3. 从URL中提取对应的ID

### 修改窗口样式

在 `init_ui()` 方法中的 `setStyleSheet()` 部分可以自定义：
- 背景颜色和透明度
- 进度条颜色
- 字体大小和颜色
- 圆角大小

## ❓ 常见问题

### Q: 程序无法启动？
A: 确保已安装所有依赖：`pip install -r requirements.txt`

### Q: 无法获取视频列表？
A: B站API有访问限制，程序会自动降级到打开收藏夹页面

### Q: 如何完全退出程序？
A: 右键点击系统托盘图标，选择"退出"

### Q: 如何设置开机自启动？
A: 
1. **简单方法**：双击 `一键安装.bat` 或 `create_startup.bat`
2. **Python方法**：安装依赖后运行 `python setup_autostart.py`
3. 快捷方式会被添加到Windows启动文件夹

### Q: 开机自启动不生效？
A: 
1. 确保使用了 `create_startup.bat` 或正确安装了 `pywin32` 和 `winshell`
2. 检查启动文件夹：`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`
3. 确认快捷方式"休息提醒.lnk"存在

### Q: 如何显示/隐藏挂件？
A: 
1. **双击**系统托盘图标（最快）
2. 右键托盘图标选择"显示/隐藏"
3. 点击窗口右上角"-"按钮最小化到任务栏

### Q: 挂件位置不对？
A: 
1. 程序启动时会自动定位到屏幕右侧中间
2. 可以用鼠标拖动到任意位置
3. 右键托盘图标选择"重置位置到右侧"恢复默认位置

### Q: 电池监控不准确？
A: 
1. 确保已安装 `psutil` 库
2. 某些笔记本电脑的电池驱动可能不完全兼容
3. 台式机会显示"无电池"状态

### Q: 断电警告会一直弹吗？
A: 不会，只在断电时弹一次，重新充电后自动关闭弹窗

### Q: 视频会打开多个吗？
A: 不会，每次只打开一个随机视频
