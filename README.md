# 休息提醒桌面挂件

每小时提醒休息，随机打开 B 站收藏夹视频，飞书同步学习数据，电池监控，每日数据追踪。

## 更新日志 v1.4

- 🖱️ **侧边栏模式**：点击关闭按钮隐藏到桌面右侧边缘，鼠标滑到右侧区域自动呼出窗口

## 功能

- **自动循环计时**：60 分钟倒计时完成后自动重启，无需手动操作
- **B站视频**：每小时结束随机打开收藏夹视频；每 3 小时打开护眼视频
- **每日数据追踪**：记录并显示学习时长、电脑使用时长、设备故障次数
- **数据持久化**：每日数据保存到 `daily_records.json`，支持历史查看
- **飞书集成准备**：架构已支持飞书多维表格同步（详见《飞书设置说明.md》）
- **电池监控**：实时电量显示，断电自动提醒（只提醒一次）
- **音频设备监控**：自动检测声音设备状态，设备异常时记录故障并提醒
- **22:00 倒计时**：4:30~22:00 可视化进度（倒计时模式）
- **电脑使用监控**：今天总使用时长 XXHXXmin，每 3 小时循环提醒
- **侧边栏模式**：点击关闭按钮隐藏到桌面右侧边缘，鼠标滑到右侧区域自动呼出
- **托盘常驻**：最小化到系统托盘，双击显示/隐藏
- **开机自启**：注册表方式，托盘右键可开关

## 快速开始

```
双击 一键安装.bat
```

自动完成：检查 Python → 安装依赖 → 设置开机自启 → 启动看门狗。

## 启动方式

| 方式 | 命令 |
|------|------|
| 看门狗（推荐） | `pythonw watchdog.py` |
| 直接启动 | `pythonw rest_reminder.py` |
| 调试模式 | `python rest_reminder.py` |

## 卸载

```
双击 卸载.bat
```

## 项目结构

```
rest_reminder.py          主程序（包含飞书数据追踪功能）
watchdog.py               看门狗（崩溃自动重启）
cute_icon.ico/png         图标
requirements.txt          依赖：PyQt5, requests, psutil
一键安装.bat              安装 + 自启 + 启动看门狗
卸载.bat                  移除自启 + 停止进程
run.bat                   手动启动
CLAUDE.md                 开发文档
飞书设置说明.md           飞书多维表格设置指南
daily_records.json        每日数据记录（自动生成）
daily_tracker_state.json  追踪器状态文件（自动生成）
```

## 自定义

| 配置 | 位置 | 默认值 |
|------|------|--------|
| 提醒间隔 | `self.interval_minutes` | 60 分钟 |
| 收藏夹 ID | `get_bilibili_videos()` 内 `fid` | 3648313921 |
| 用户 ID | `get_bilibili_videos()` 内 `mid` | 529362421 |
| 飞书轮询间隔 | `setup_timer()` | 30 分钟 |
| 学习目标 | `study_progress_bar.setMaximum` | 14 小时 |
