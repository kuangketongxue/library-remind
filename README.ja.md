## ✨ 機能一覧

| 機能 | 説明 |
|------|------|
| **60分集中サイクル** | 学習→5分マインドフルネス→5分休憩→Bilibili自動再生 |
| **5タブダッシュボード** | 今日/AIレポート/傾向分析/設定/について |
| **レビュー記録** | 各セッション後に科目+タグ+スコア(1-100) |
| **🤖 AI学習分析** | 日報/週報/月報/四半期報/年報 |
| **傾向グラフ** | 学習時間バーチャート + ホバー表示 |
| **20-20-20  Eye Care** | 20分ごとに軽いオーバーレイ提醒 |
| **トレイ + フローティングボール** | バックグラウンド常駐、ワンクリック制御 |
| **自動起動** | システムログイン後に自動起動 |
