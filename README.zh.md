## ✨ 功能一览

| 功能 | 说明 |
|------|------|
| **60分钟专注循环** | 学习→5分钟请辨倒计时→5分钟休息→自动开B站 |
| **5标签页主界面** | 今日概览/AI报告/趋势分析/设置/关于 |
| **复盘记录** | 每小时学科+标签+评分1-100分 |
| **🤖 AI 学习分析** | 日报/周报/月报/季报/年报 |
| **趋势图表** | 学习时长柱状图 + 悬浮提示 |
| **20-20-20 护眼提醒** | 每20分钟轻量浮窗 |
| **托盘 + 浮球** | 后台常驻，一键控制 |
| **开机自启** | 系统登录后自动运行 |

## 🚀 快速开始

```
# 直接运行
python rest_reminder.py

# 或双击启动
_launch.vbs
```
