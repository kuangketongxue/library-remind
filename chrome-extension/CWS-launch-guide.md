## 二、隐私实践（Privacy Practices）

| 字段 | 填写内容 |
|---|---|
| **隐私政策 URL** | `https://crazy-rest-reminder.pages.dev/privacy-chrome` |

**权限正当理由**（每个权限都会单独提问，逐项填）：

| 权限 | 正当理由 |
|---|---|
| `alarms` | 用于设置学习定时器（60 分钟）和护眼提醒（20 分钟）的定时任务，在时间到达时触发通知和页面跳转。 |
| `storage` | 用于本地保存用户设置、学习记录、复盘数据和成就进度。所有数据仅存储在用户浏览器本地。 |
| `notifications` | 用于在学习和休息时间到达时发送桌面通知，并弹出护眼提醒窗口。 |

**单一用途说明**（Single Purpose，审查员必问）：

```
本扩展的唯一目的是帮助用户管理学习节奏：定时学习/休息循环 + 护眼提醒 + 复盘记录 + 趋势统计。所有功能均围绕这一目的设计，不收集、不共享用户数据（除非用户主动启用可选的 GitHub 备份/邮件/AI 报告功能）。
```

**不会声明的事项**（Certifications，全选"否"）：
- 本扩展 **不会** 将用户数据出售给第三方
- 本扩展 **不会** 将用户数据用于与本扩展目的无关的用途
- 本扩展 **不会** 将用户数据转让给第三方（除非法律要求）

## 四、提交前最终检查清单

扩展目录 `chrome-extension/` 应包含以下文件（删除无关文件后再打包）：

```
chrome-extension/
├── manifest.json        ✓
├── background.js        ✓
├── popup.html           ✓
├── popup.css            ✓
├── popup.js             ✓
├── options.html         ✓
├── options.css          ✓
├── options.js           ✓
├── review.html          ✓
├── trends.html          ✓
├── achievements.html    ✓
├── reports.html         ✓
├── eye-rest.html        ✓
├── icons/
│   ├── icon16.png       ✓
│   ├── icon48.png       ✓
│   └── icon128.png      ✓
└── privacy-policy.md    ✓ 参考文件（不上传）
```

**打包上传**：在 VS Code / 资源管理器中右键 `chrome-extension/` 文件夹 → 压缩为 ZIP → 上传到开发者后台。

**不要打包**：
- `.md` 文件（manifest 不引用）
- `.git/` 目录
- `node_modules/` 目录
