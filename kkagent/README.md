# kkagent

个人智能体网站：支持注册登录、对话存储、模型路由、特质索引、月度深访、日记复盘和管理员后台。

## 快速开始

1. 安装依赖：
   npm install
2. 初始化数据库：
   npm run db:init
3. 启动开发：
   npm run dev
4. 打开浏览器：
   http://localhost:3000

## 已实现能力

- 首个注册账号自动管理员
- 历史对话：搜索、置顶、删除、新建
- 模型路由：默认 openroute/free + NVIDIA 模型池
- 高级模式：多模型并发共识
- 每轮对话后自动产出结构化特质索引
- 日记：成功日记 / 赚钱日记
- Sleep Mode：手动触发当天对话汇总
- 月度深访：自动生成访谈大纲与进化报告
- 管理员后台：全站 Token、用户量、会话量、公告发布
- 设置页：API Key 本地加密保存并可实时修改

## 部署

- 平台：Vercel
- 数据库：Supabase Postgres
- 生产环境请在 Vercel 项目中设置环境变量
